# 数据模型进度

数据库是项目内容、修订和来源的唯一权威存储，不使用资料 Git 仓库。[ADR 0003](../adr/0003-database-and-agent-cache.md)说明总体方向，[ADR 0004](../adr/0004-operation-snapshot-resolution.md)确定成功操作承载项目版本、整张图按同一项目版本解析。

**数据库、共同保存／查询服务和第 2 阶段 MCP 工具已实现。提供固定版本文件清单和字节读取；真实 Agent 宿主落盘仍待验证；项目入口和综述页面已接入，其余业务页面待接入。**

| 内容       | 当前实现                                                       | 后续工作                       |
| ---------- | -------------------------------------------------------------- | ------------------------------ |
| 项目和综述 | 创建空项目、当前内容、修订、原始来源；MCP／HTTP 及综述页已接入 | 更丰富的来源及修订展示         |
| 需求推进   | 需求、记录、回顾、状态变化依据、当前及固定历史关联             | 回顾工具、展示与时间线默认排序 |
| 业务设计   | 节点、连线、图、技术说明、成员、完整候选图校验                 | X6/ELK 映射及真实交互          |
| 共同保存   | 原子事务、操作去重、版本冲突、项目归属、移除与恢复             | 外部入口权限、传输及错误契约   |
| 历史读取   | 项目快照、具体修订、历史分页和来源查询；MCP 导出及引用闭包     | 真实 Agent 宿主落盘验证        |
| 数据迁移   | Drizzle 顺序迁移、校验已应用文件、拒绝未知业务库               | 部署和跨平台验收               |

实现字段、目录和边界见[存储实现](storage-implementation.md)，版本语义见[快照保存模型](snapshot-save-model.md)，Agent 的后续流程见[存储及 Agent 读写流程](storage-and-agent-flow.md)。
