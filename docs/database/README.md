# 数据模型进度

最新已确认方向见[数据库保存资料、Agent 拉取本地读取副本](../adr/0003-database-and-agent-cache.md)：数据库是当前内容、修订和来源的权威存储；Agent 经 MCP 初始化拉取资料，日常读本地文件，正式修改通过 MCP 提交。先不使用资料 Git 仓库，也不要求独立连接器。完整流程以[存储及 Agent 读写流程](storage-and-agent-flow.md)为入口，业务链路尚未实现。

共同版本模型见[项目快照、保存操作及对象修订](snapshot-save-model.md)：成功操作直接承载项目版本，不再另建登记表；各模块修订通过操作归入项目快照。附[协调层 SQL 草案](snapshot-coordination-draft.sql)及临时 SQLite 验证，尚未实现业务保存服务。

此前的[数据结构与映射说明](data-mapping.md)及下列 SQL 草案作为各模块字段和约束的设计基础，**不能直接作为正式迁移或当前已实现的存储架构**。共同层、项目／综述及业务设计 SQL 已可组合，封存守卫和操作索引已加入；需求／回顾及完整跨模块引用仍需补齐。当前代码仍是本机基础服务。
