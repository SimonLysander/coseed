# 项目入口与综述阅读

状态：已实现项目选择、创建、切换和真实综述阅读。需求推进、业务设计页面、网页正文编辑和远程权限尚未接入。

## 使用流程

首次进入且没有保存的项目选择时，页面提供“创建项目”和“选择已有项目”。不会自动选列表第一项，也不会灌入 CoSeed 或 Claude Monitor 示例。

左侧项目按钮打开 Ant Design 项目选择弹窗。名称搜索是服务端子串筛选，列表按稳定 ID 分页，支持加载更多；相同名称仍是不同项目。创建只填写名称，仓库定位不是必填项。创建成功进入空项目，版本为 0，没有编造的综述、需求或设计。

Agent 用已有 MCP 工具保存综述后，页面通过真实 HTTP 接口读取。浏览器回到窗口时由 TanStack Query 检查过期查询，也可点击刷新；本阶段没有服务端推送或持续轮询，不能宣称页面与后台实时同步。

## 链接和选择

```text
#/overview                                      首次入口，或恢复上次选择
#/projects/<projectId>/overview                  读取明确项目
#/projects/<projectId>/overview/product          产品说明
#/projects/<projectId>/overview/concepts         核心概念
#/projects/<projectId>/overview/examples         使用示例
#/projects/<projectId>/overview/example/<id>     指定示例小节
#/agent-guide                                   接入说明
```

React Router 的 HashRouter 管理路由。直接项目链接优先于上次选择；示例链接使用 URL 编码后的稳定小节 ID，不靠标题或数组下标。重命名或排序不会改变链接含义。缺失项目显示错误及重新选择入口，不偷偷切到另一个项目。

浏览器 localStorage 只记住项目选择；正文仍从数据库读取。这个偏好不是项目资料缓存，也不属于业务项目仓库。

## 一次创建如何完成

Web 创建也复用 `ProjectContentService.createProject`，与 MCP 保持相同的修订和来源约束。HTTP 入口独立提供 entrypoint=web、actorKind=human，显示名明确为未认证的本机用户；不接受调用方覆盖这些字段。

浏览器为本次创建生成 UUID 操作标识；原请求保存在 sessionStorage。请求失败或响应丢失时不自动重试写入，由人操作“重试创建”，沿用原标识和内容；关闭弹窗或刷新同一标签页后仍可恢复。成功后清理待确认请求。服务器返回原成功回执，不重复创建项目。

sessionStorage 是有界的待确认请求信息，不是服务器草稿表或业务历史。浏览器拒绝保存时显示实际警告，当前页面仍保留请求；关闭标签页后不承诺恢复。创建成功之后若列表刷新失败，不重复执行创建。

## 综述如何阅读

页面采用已有全局阅读宽度、系统字体、松针绿及明暗主题，不设顶栏。右侧使用 Ant Design Anchor 目录，窄屏使用目录菜单。标题下分别显示项目内容版本和综述保存时间，二者不是同一个对象的修订号。

1. 产品说明：原样保留自然 Markdown 段落及小标题。
2. 核心概念：完整关系图加词条解释，每个词条只出现一次，按原数组顺序显示；不把多父关系强行改成单父树。
3. 使用示例：先交代背景，再按“小标题 → 对应用例图 → 例子正文”逐节阅读，不添加总用例图。

空综述、空概念和空示例使用各自真实空状态。Markdown 使用已有 markdown-it，禁用原始 HTML，保留常规 Markdown 能力。项目名称、概念及图标签作为文字渲染，不执行内容里的指令。

## 图形实现和边界

图从共享内容结构派生，不新增坐标字段或把图形引擎实例存进数据库。X6 负责呈现，ELK Layered 在共享 Web Worker 中计算布局；在没有真实图内容时不加载图形引擎或启动 Worker。

概念图保留种属、组成及业务关联。用例图按本节 useCaseIds 选取用例和实际参与角色，角色在系统边界外，用例在边界内，参与线没有方向，不表示操作先后。暂不增加 include、extend 或用例泛化。

ELK 计算节点和折线，X6 使用原生 orth 锚点和 boundary 连接点接到实际形状，避免连接人物节点的不可见矩形边缘。标签使用 X6 文字测量和 ELK 标签位置，长文本按内容测量。图只读并自动适应容器，不提供缩放、平移、拖动或 Hover 详情。

ResizeObserver 观察外层阅读容器，不能观察被引擎固定宽度的旧画布来判断页面宽度。切换明暗只改语义色，不布局；不受影响的概念和示例模型分别 memoize，单独修改产品正文不重算其他图。卸载清理图、观察器和 Worker，过期布局结果不覆盖新页面。

当前验证的是小规模真实结构样例、中文、多个角色／用例、主题与 320px 至桌面宽度；不是大图容量承诺。Worker 和 X6 产物仍较大，按需加载不等于已经完成全部性能预算或压测。

## HTTP 契约

| 路径                                  | 职责                             |
| ------------------------------------- | -------------------------------- |
| GET /api/projects                     | 服务端搜索及分页发现项目         |
| POST /api/projects                    | 幂等创建空项目                   |
| GET /api/projects/:projectId          | 仅读项目基本资料和当前版本       |
| GET /api/projects/:projectId/overview | 一致读取项目和当前或指定版本综述 |

字段、必填和错误定义以 `src/contracts/projects-http.ts`、生成的 `docs/api/openapi.json` 为准，不在文档复制一套字段表。读取视图在同一数据库事务固定版本；读取综述不加载整个项目设计快照。HTTP 缓存为 no-store，前端业务查询由 TanStack Query 管理并按项目 ID 隔离。

网络或服务端读取失败最多重试一次，4xx 不自动重试。15 秒超时及切换项目的请求取消使用原生 AbortSignal。无数据时明确报错；同项目刷新失败时保留上次内容并标明版本和失败状态。不能把旧副本当成本次查询成功。

服务仍绑定回环地址并检查 Host／Origin，HTTP 请求上限仍为 1 MiB。项目引用归属检查不等于远程身份及权限，未新增认证、租户或对外部署。
