# 业务设计阅读

当前正式实现；内容类型和保存规则以 `src/contracts/content/business-design.ts`、[数据模型](../database/business-design.md)为准。

## 入口与版本

左侧「业务设计」进入当前项目。有且只有一张项目全景图时直接打开，否则列出真实图纸供选择；没有内容时显示空状态，不注入示例。模块有明确内部图才提供入口，多张内部图供选择，不按名称或 ID 猜测。

路由为 `#/projects/:projectId/business/diagrams/:diagramId`。无 version 参数读取当前项目版本；`?version=N` 固定历史项目版本。全景进入内部、返回全景均沿用已读版本，避免一次阅读混入不同版本。「查看当前版本」解除固定；刷新重新读取当前内容。

服务在同一 SQLite 读事务中取得图成员、对象、归属、关系、说明和核心实现路径。只解析所选图和必要归属，不读取整个项目快照、需求历史或来源全文。共享节点更正后，当前图采用新内容，历史图保留旧内容；图本身修订号不代表完整内容版本。

## 节点与区域

- 全景：模块及必要的外部系统，名称加凝练的业务说明；有内部图的模块提供导航。
- 内部：处理组件显示名称和职责；数据对象再显示 TS 类型与行内注释，不列类、方法、CRUD 或负责操作。
- 内外由 scope 和 owner 推导。内部对象位于模块边界内，其他模块或外部系统的对象按实际 owner 分组，位于边界外。
- 实现路径取唯一核心来源；按真实目录树形成区域，压缩只有一个目录子级的中间层。路径有 `modules/` 时从该段开始，否则保留真实仓库相对目录。路径只显示在区域标题且不换行；没有来源不编造目录。
- 无 Hover；内部节点不展开、不编辑、不跳到第三层。字段和说明直接可读。

## 关系

业务说明和语义操作同时显示；请求参数、读取条件、修改内容和返回含义不可相互代替。

| 类型     | 线型                             | 直接显示                                             |
| -------- | -------------------------------- | ---------------------------------------------------- |
| 功能依赖 | 虚线、开放箭头，依赖方指向提供方 | 依赖的业务能力                                       |
| 模块关联 | 实线、无箭头                     | 具体业务联系                                         |
| 调用     | 虚线、开放箭头，调用方指向被调方 | `«call»`、业务说明、`动作（核心输入）：结果`         |
| 读取     | 虚线、开放箭头，组件指向对象     | `«read»`、业务说明、`读取动作（查询依据）：读取内容` |
| 写入     | 虚线、开放箭头，组件指向对象     | `«write»`、业务说明、`动作（定位依据；修改内容）`    |
| 对象关联 | 实线、无箭头                     | 业务说明、已知关联字段，实际两端的已知数量           |
| 事件     | 点线、开放箭头，发布方指向订阅方 | `«event»`、业务说明、`事件（核心载荷）`              |

调用结果明确为 none 才显示「无返回」，NULL 显示「返回待确认」。未知数量不补写；已确认的数量绑定源端／目标端，不因布局换向而交换。返回不增加反向调用线，事件不推断异步可靠性。此处借用 UML 基本关系，不是完整 UML 编辑器。

## 技术说明

一个成员的说明放在该节点内。多个成员的说明以编号卡片和独立轮廓表达，各成员有对应编号。轮廓可分离、可交叉；不通过放大矩形误圈无关节点，也不复制节点或改变目录父级。成员关系来自明确 ID 集合，不能从几何包含反推。

说明正文为解决的问题并融入设计理由，不增加范围字段、规则清单或固定主题模板。

## 布局与交互

统一用 ELK layered 计算嵌套区域、节点、边和标签；真实字体及 React 卡片尺寸先参与测量。比较 DOWN／RIGHT 的有效候选，按面积与宽高比选择，无业务专用坐标。边使用 ELK 的声明父坐标，文字必须提供 text 与尺寸，避免标签原点重叠或跨层坐标偏移。

布局输出检查节点重叠、关系文字遮挡及相互遮挡、连线穿过非端点和非正交路径；无有效候选时明确显示绘制失败并可重试。检查通过不代表满足所有视觉审美或语义完整性。

X6 保留 ELK 路径，不再另跑局部路由。支持缩放、滚轮、空白拖动、适应画布与 100%。全图适应后比例过小时，默认 100% 并定位内部连接数最多的节点，保留字的可读性；这仍不能让大图所有文字同时可读。主题只换颜色，容器尺寸变化只调整视口，均不重新布局。卸载销毁 Graph 并释放共享 Worker；异步旧结果不得覆盖新页面。

轮廓复用 polygon-clipping 的 union/difference 运算；ELK commentBox 用于说明卡片布局，其辅助边不渲染为业务关系。颜色、字号、间距来自全局设计系统。根页面的 body 样式只作用于 `html > body`，不影响 X6 的 XHTML 卡片容器。

## 验证边界

浏览器用虚构的完整模块数据验证，不污染开发数据库。覆盖全景进入内部、字段及关系、交叉范围、实际卡片尺寸、明暗切换、缩放拖动、窗口变化、反复卸载重建、历史和项目隔离。自动校验引用、类型及几何，不能自动证明职责划分正交完备，仍需人审阅。

远程部署权限、Web 编辑、图形容量承诺、复杂大图的阅读筛选不在本阶段实现范围。
