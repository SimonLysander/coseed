# 内容编写约定审阅稿

这是既有约定的首批整理和页面设计，用于逐项核对，尚未替换 `src/server/mcp/guides.ts` 的运行指南，也不是一套新业务规则。

页面 `#/writing-guide/overview` 从「Agent 接入」进入；按项目综述、需求推进、业务设计和共同约定分主题。默认阅读正文，右侧目录定位；「核对约定」用同一份内容展示出处。窄屏采用主题和章节菜单。均复用全局设计系统、Ant Design、既有 Markdown 阅读组件，无新依赖、数据库或 MCP 协议变更。

`catalog.json` 是当前审阅清单的唯一正文源。条目标题用于导航，excerpt 保留摘录；source 区分本次会话可见用户原话和仓库文档记录。用户原话没有取得平台消息编号，不能伪造；文档记录不能自动视为逐条找回了用户原话。editorialNote 仅解释已有明确替代关系，页面标为「核对说明」。所有 document 摘录由测试与仓库原文逐字匹配。

当前共 50 条，范围限于当前可见用户消息和列出的文档；此前助手回复及完整历史尚未恢复。各主题末尾保留缺口，不补造产品句式、概念粒度、强制字数或技术主题枚举。特别保留概念缩进约定与当前平铺实现的差异，不以代码替代需求。

下一阶段根据核对结果整理规范正文及 Agent 指南的同源读取；本次未执行该替换，也没有改变现有内容的 Schema、保存规则或用户项目资料。历史中明确被后来修改的要求保留出处，例如总用例图的保留要求后来被用户明确取消。
