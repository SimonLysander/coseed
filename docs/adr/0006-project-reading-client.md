# ADR 0006：项目阅读使用独立 HTTP 视图和成熟客户端库

状态：已实施于项目入口和综述阅读。

## 背景

初始化工作台只有静态页和服务状态检查。接入真实项目后，需要明确项目的链接、搜索分页、取消过期请求、刷新和错误状态。继续扩展手写 hash 分发及请求状态管理，会重复建设通用能力，不符合既定复用原则。

## 决定

- React Router 的 HashRouter 管理路由，保留已有 hash 地址及静态包交付方式；项目和示例均使用稳定 ID。
- TanStack Query 管理业务服务器状态，按项目隔离查询缓存、处理取消、过期和失效；客户端缓存不成为权威存储。
- Web 使用只读 HTTP 视图及空项目创建入口，MCP 继续面向 Agent；两个入口复用同一内容服务和数据库约束。
- 综述读取只解析指定版本的项目和综述，不为页面读取所有设计、来源与历史。写作仍经 MCP 维护，不增加网页发布流程。
- 浏览器使用标准 UUID 和 sessionStorage 保留待确认创建请求，同一请求复用操作标记；不新增服务器草稿表或提交票据。

实际依赖版本以 package.json 和 lockfile 为准。选型没有替换已确定的 React、Ant Design、Motion、X6 或 ELK。

## 影响和边界

客户端增加两个成熟依赖，换取明确的路由和服务器状态边界。HTTP 读取 DTO 不等同于 MCP 的完整导出格式，也不复制另一套业务写入规则。React Router 和 TanStack Query 的状态不写进业务内容，不产生项目修订。

本阶段采用焦点恢复和手动刷新，不宣称实时同步。没有远程认证、租户、SSR、离线业务写入或跨浏览器缓存同步。图和 Worker 按需加载；大图性能仍按既有验收计划单独验证。
